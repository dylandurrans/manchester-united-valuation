# Manchester United plc (NYSE: MANU) — Equity Valuation

**DCF Valuation · Comparable Company Analysis · Investment Research**

## Project Overview

Independent equity research evaluating Manchester United's financial performance, intrinsic valuation and investment outlook.

The project includes a five-year financial forecast, three DCF scenarios (Base, Bull and Bear), a WACC calculation, and comparable-company valuation using publicly traded European football clubs.

## Investment Conclusion

**Recommendation: HOLD**

The DCF scenarios produce negative equity values under the model's projected cash flows, highlighting the limitations of a perpetual-growth terminal value when free cash flow remains negative. Comparable-company analysis provides an alternative valuation benchmark.
